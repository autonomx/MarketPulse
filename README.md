# MarketPulse

Built for real-time market monitoring, premarket gappers, breaking catalysts, and momentum signals.

MarketPulse is the Omnix trading app as one self-contained desktop program: charts, scanners, alerts, paper
trading, strategies, research and LLM-assisted analysis, with PostgreSQL, Python and the web UI inside the installer.
Windows first; macOS next. The plan is [docs/ROADMAP.md](docs/ROADMAP.md).

## How it relates to Omnix

Omnix is the authority: trading is developed there, and MarketPulse mirrors it.

| Kind | Paths | Rule |
|------|-------|------|
| **Mirrored** | `src/app/`, the trading and auth tests under `src/tests/`, `scripts/run_omnix_gateway.py` and friends, `requirements/`, `resources/trading/` fixtures, `web/src/`, web configs | Byte-identical to Omnix at the commit in `sync/omnix-sync.json`. **Never edit them here**: change Omnix, then sync. |
| **Derived** | `pyproject.toml`, `web/package.json` | Generated by the sync tool from Omnix files plus `sync/templates/`. |
| **Owned** | `src/marketpulse/`, `src/tests_marketpulse/`, `web/marketpulse/`, `desktop/`, `build/`, `sync/`, `docs/` | MarketPulse's own code. |

```
python sync/sync_from_omnix.py sync --to <omnix ref>   # mirror an Omnix commit
python sync/sync_from_omnix.py check                   # fail on any drift
python sync/sync_from_omnix.py tests                   # the trading test set
```

MarketPulse never authors database migrations: the schema comes from Omnix (one migration namespace).

## Decisions

| ID | Decision |
|----|----------|
| D-1 | Fork, with Omnix as authority. |
| D-2 | Fully self-contained desktop app. |
| D-3 | LLM features included. |
| D-4 | Accounts included (sign-in, guests, invites, Google). |
| D-5 | Windows first; macOS after. |
| D-6 | Source is Omnix `main` (the Phase 1 seams are on Omnix branch `marketpulse-seams` until merged). |
| D-7 | TradingView Desktop is an architecture reference only; nothing from it is copied. |
| D-8 | `ibapi` is bundled, from Interactive Brokers' official distribution. |
| D-9 | Research handoffs come from a separate data-only repository. |
| D-10 | The look closely resembles TradingView Desktop, built from our own code and assets. |
| D-11 | Omnix trading takes that look too; it is built once in Omnix. |

## Layout

```
src/app/            mirrored Omnix backend (only the trading feature is enabled)
src/marketpulse/    desktop ASGI wrapper, child environment, diagnostics
web/src/            mirrored Omnix web source
web/marketpulse/    the MarketPulse web entry (registers only trading)
desktop/            Electron shell and supervisor
build/              scripts that stage CPython, PostgreSQL and ibapi into the installer
sync/               the Omnix mirror manifest, lock and tool
```
