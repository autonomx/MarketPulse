# Developing MarketPulse

MarketPulse is the Omnix trading app as one self-contained desktop program, with PostgreSQL, Python and the web UI
inside the installer. Windows first; macOS next. The plan and its status are in [ROADMAP.md](ROADMAP.md); the macOS
build is in [MACOS.md](MACOS.md); contribution rules and the gate set are in [CONTRIBUTING.md](../CONTRIBUTING.md).

## How it relates to Omnix

Omnix is the authority: trading is developed there, and MarketPulse mirrors it.

| Kind | Paths | Rule |
|------|-------|------|
| **Mirrored** | `src/app/` (other features keep only their `feature.py`, declarations and migrations: see `sync/omnix-manifest.toml`), the trading and auth tests under `src/tests/`, `scripts/run_omnix_gateway.py` and friends, `requirements/`, `resources/trading/` fixtures, `docs/architecture/` trading records, `web/src/`, web configs | Byte-identical to Omnix at the commit in `sync/omnix-sync.json`. **Never edit them here**: change Omnix, then sync. |
| **Derived** | `pyproject.toml`, `web/package.json` | Generated by the sync tool from Omnix files plus `sync/templates/`. |
| **Owned** | `src/marketpulse/`, `src/tests_marketpulse/`, `web/marketpulse/`, `desktop/`, `build/`, `brand/`, `sync/`, `docs/` (except `docs/architecture/`) | MarketPulse's own code. |

```
python sync/sync_from_omnix.py sync --to <omnix ref>   # mirror an Omnix commit
python sync/sync_from_omnix.py check                   # fail on any drift
python sync/sync_from_omnix.py tests                   # the trading test set
```

MarketPulse never authors database migrations: the schema comes from Omnix (one migration namespace).

## Build and test (Windows)

Needs Python 3.11 with the dev dependencies, Node 22.12+, and the ibapi 10.50.2 sources in
`build/cache/ibapi/ibapi-10.50.2/` (pinned by tree hash in `build/pins.json`). macOS: [MACOS.md](MACOS.md).

```
npm --prefix web ci && npm --prefix web run build          # the MarketPulse web app
python build/stage.py all                                   # Python, PostgreSQL, app and web into build/stage, pruned and checked
npm --prefix desktop ci && npm --prefix desktop run dist    # desktop/release/MarketPulse-Setup-<version>.exe
```

The gate set ([ROADMAP §6](ROADMAP.md)) runs with `OMNIX_TEST_DATABASE_URL` pointing at a scratch PostgreSQL:

```
python sync/sync_from_omnix.py check
OMNIX_FEATURES=trading python -m pytest $(python sync/sync_from_omnix.py tests) src/tests_marketpulse -q
npm --prefix desktop run test                               # Electron smoke + unit suites on build/stage
```

Signing (Azure Artifact Signing or a certificate file) and the release feed are set up in
`desktop/scripts/dist.mjs` and `desktop/electron-builder.yml`.

## Layout

```
src/app/            mirrored Omnix backend: the platform and trading; other features' schema and declarations only
src/marketpulse/    supervisor, desktop ASGI wrapper, child environment, Omnix data import
web/src/            mirrored Omnix web source
web/marketpulse/    the MarketPulse web entry (registers only trading)
desktop/            Electron shell (windows, tray, notifications, updates, installer config)
build/              stage.py (CPython, PostgreSQL and ibapi into the installer), pins, brand rendering
sync/               the Omnix mirror manifest, lock and tool
docs/screenshots/   the README's screenshots, taken from the real app with live market data
```
